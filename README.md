# TEMPLO — Premium Fitness Landing Page

> No vienes solo a entrenar. Vienes a construirte.

Landing page estática para TEMPLO, un entorno premium de entrenamiento guiado en Cochabamba con Power Plate, calistenia, máquinas, fuerza y entrenamiento funcional.

Conversión principal: WhatsApp.

## Quick Start

```bash
# Open directly in browser
open index.html

# Or serve locally
python3 -m http.server 8000
```
