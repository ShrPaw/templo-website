# Reference Comparison — Commando Studio vs TEMPLO

**Date:** 2026-05-16
**Reference:** https://commandostudio.com/mx/#nosotros

---

## 1. What the Reference Does Well

### Visual Rhythm
- Each discipline/service gets its own full-width block — not crammed into a grid
- Strong alternation between image-led and text-led sections
- Clear vertical pacing: hero → services → community → coaches → footer
- Generous whitespace between sections

### Service Clarity
- Each service block has: large name + short description + "Conoce Más" + "Reservar"
- Service names are bold, uppercase, repeated as visual anchors
- Each offering feels like its own mini-section, not a card in a grid
- Clear "what is it + who is it for + next action" structure

### CTA / Reservation Flow
- "Reservar" appears repeatedly but doesn't feel desperate — it feels like a booking system
- Primary CTA is always visible in nav
- Each service block has its own "Reservar" link
- Footer has "Reserva tu clase" as a prominent action
- CTAs are calm, direct, professional

### Coach Visibility
- Coaches section exists as a real section with "Ver todos" link
- Grid of coaches with visual presence
- Builds trust through human connection

### Community / Social Proof
- Stats section: "+2.5M CLASES", "+190 COACHES", "+45 SALONES"
- Lifestyle messaging: "Endorfinas, comunidad y estilo de vida"
- Creates energy and credibility through numbers

### Typography
- Bold, uppercase headings dominate
- Strong contrast between labels and body text
- Editorial feel — headings are visual elements, not just text
- Consistent weight and spacing system

### Footer
- Structured with clear columns: contact, navigation, social
- "Reserva tu clase" repeated as footer CTA
- Social links prominent
- Professional, not just functional

### Mobile
- CTAs remain prominent
- Service blocks stack cleanly
- Visual rhythm preserved on small screens

---

## 2. What TEMPLO Lacks Compared to the Reference

| Area | Commando Studio | TEMPLO Gap |
|------|----------------|------------|
| Service blocks | Full-width, bold, each is a section | Cards in a grid, less impact |
| CTA flow | "Reservar" feels like booking system | WhatsApp feels like "contact us" |
| Section rhythm | Strong alternation, generous spacing | More uniform, less dynamic |
| Typography | Bold, editorial, visual anchors | Good but less dramatic |
| Community proof | Stats + lifestyle messaging | Metrics exist but less energy |
| Coach presence | Dedicated section with grid | Teaser only, initials not photos |
| Footer | Structured, multi-column, CTA | Functional but basic |
| Visual energy | Vibrant, alive, studio feel | Calm but could be more dynamic |

---

## 3. What Should NOT Be Copied

- Exact brand voice (Commando is energetic/hype; TEMPLO is calm/intense)
- Fake stats ("+2.5M classes" — TEMPLO doesn't have this)
- Multi-location structure (TEMPLO is one studio)
- Bright/neon color scheme (TEMPLO is dark premium)
- "Endorfinas" messaging (different brand personality)
- Exact CTA wording ("Reservar" → TEMPLO uses WhatsApp)
- Over-commercial/hype elements
- Exact layout structure
- Commando-specific discipline names

---

## 4. Adaptation Strategy for TEMPLO

### Principle → TEMPLO Translation

| Principle | Commando Implementation | TEMPLO Adaptation |
|-----------|------------------------|-------------------|
| Service clarity | Full-width blocks per discipline | Improve existing cards: stronger titles, clearer descriptions, individual CTAs |
| CTA flow | "Reservar" popup system | "Consultar disponibilidad" via WhatsApp — positioned as booking, not just contact |
| Section rhythm | Bold alternation | Add stronger visual breaks, editorial labels, more contrast |
| Typography | Huge bold headings | Increase heading scale, use brand-seal accent more strategically |
| Community proof | Stats + lifestyle | Honest metrics (8 coaches, 5 experiences, 6 days) with more energy |
| Coach presence | Full grid section | Strengthen existing teaser, add more visual weight |
| Footer | Structured with CTA | Add more structure, repeat WhatsApp as booking action |
| Visual energy | Bright, vibrant | Dark premium energy — stronger contrast, gold accents, better rhythm |

### Brand Translation
- Commando = bright, energetic, endorphins, community, hype
- TEMPLO = dark, grounded, discipline, transformation, calm intensity
- Both = serious about training, clear about offerings, professional booking flow

TEMPLO should feel like the quieter, more serious cousin — not a copy, but sharing the same DNA of commercial clarity and studio professionalism.
